# Contributing

Thanks for helping improve InjectWall.

1. Open an issue describing the bug or proposed change.
2. Keep examples synthetic and non-sensitive. Never submit real secrets, personal data, or live malicious URLs.
3. Add or update deterministic tests for behaviour changes.
4. Run `python -m unittest discover -s tests -v` and `python -m injectwall.cli`.
5. Keep the default path offline, dependency-free, CPU-only, and easy to explain.
6. Submit a pull request with a short rationale and test output.

Please do not use this project to target systems or data without explicit authorisation.
